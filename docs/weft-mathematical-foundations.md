# 横糸の情報価値・識別限界・安全な候補縮約：条件付き数理ノート

- Research: [Issue #142](https://github.com/uobnnisiuk/footprint-sim/issues/142) / `FP-MATH-WEFT-INFORMATION-LIMITS-V1`
- Policy: `footprint-core-continuation-v1` / `footprint-math-research-v1`（2026-11-12）
- 状態: **研究著者による初稿。命題は明示した仮定の下での論証であり、独立の数学的内容審査・新規シミュレーション・現実への妥当性検証は未完了。**
- 目的: 本人の履歴（経糸）が欠けた状態で、救助者が受領した他者・端末・環境由来の情報（横糸）が、最新目撃だけでは得られない確認単位の削減をいつ可能にするか。その限界が**情報不足**か**計算方式の不足**かを分ける。完全な因果網や24縁エンジン完成を目的としない。

## 1. 定義と仮定（実装・真値との境界）

固定した公開・移動モデル `M` と対象 `Person P`、対象時刻 `t`、照会時点で救助者が入手可能な受領cutoff `τ` を指定する。`Ω_M` は `M` の下で可能な**履歴と関係構造の組**からなる集合とする。履歴には対象PersonとDeviceの別々の状態、観測が起きた時刻、公開遷移、未知の関係の選択肢を含め得る。`M` を固定した論証では、これらが「真にすべてを網羅する」ことは仮定に過ぎない。

- `E_τ` は、観測時刻でなく**救助者への受領時刻がτ以下**であり、照会で使用可能な公開命題と、その観測・受領時刻、対象entity kind、論理的役割、source observation/ancestryを組にした情報。private、未来受領、真値、未観測の実移動、生成器の乱数は含めない。
- 命題 `e` の採用可能性は「公表され受領済み」「対象が一致」「Confirmed等の意味づけが明示」「同時に成立させてよい論理役割」等の条件で判定する。`S_M(e) = {h∈Ω_M : hはeを満たす}`。不確かな代案を一つの確定した連言に変えることはできない。
- `H_M(E_τ) = {h∈Ω_M : hはE_τの宣言済み論理構造と整合する}`。欠けた関係は**関係の不存在ではなく**複数の`h`を許す。関係が初めから与えられている場合、未知関係の発見能力は評価できない。
- `R_t(h)` は対象Personが`t`に占め得るregion集合。`q_t(h)⊆U` は同じ時刻の公開region→確認単位（unit）対応で取り得る単位集合。`U` は**この論証に限る完全な有限の確認単位母集合**。`q_t`は一対一とは限らず、異なるregionが同じunitへ対応してもよい。Deviceの`q_t`をPersonのものと同一視しない。
- **完全な単位写像が仮定できる場合だけ**、情報から許される外側集合を `C*_t(E_τ) = ⋃{q_t(h): h∈H_M(E_τ)}` と定義する。実装が返す `C_alg` はこれとは別の近似。真値履歴 `h*` と実単位 `u*_t` は事後評価用であり、構築の入力ではない。
- 地域やunitへの対応が部分的・未公表なら、`C*` を完全と偽らず、`(known units, unresolved alternatives)` を一組として保持し、未解決候補に対応する場所をhard除外しない。`unknown` と「証拠が存在しない」は別。`H=∅` も「捜索場所が0」と解釈せず**矛盾・モデル不整合**と表示する。

ここでの「情報価値」は観測事実の真偽や救命率ではなく、**固定した仮定のもとで実行可能な確認単位の外側集合が狭まること**とする。`|H|`、`|R|`、`|C*|`、現場で必要な訪問場所・作業時間・費用は異なる量である。

## 2. 命題I：同じ受領情報では区別できない世界がある（識別限界）

**命題I-1（条件付き、直接証明）**。固定した`M,t,τ`で、受領可能なすべての入力が一致する2履歴`h_A,h_B∈H_M(E_τ)`があり、実際の対象Personの確認単位がそれぞれ異なる単位`U_A≠U_B`だとする。この2世界を両方許す情報だけを入力とする**決定的方式**は、常に正しい**単一の**確認単位を出力できない。安全な外側候補は少なくとも`U_A,U_B`を含める必要がある。

**証明**。方式に渡る`(M,t,τ,E_τ)`は2世界で同一なので、その出力も同一である。出力を単一`U_A`とすれば`h_B`の世界では誤り、単一`U_B`なら`h_A`の世界では誤る。他の単位なら両方で誤る。真値を隠した条件で両世界に成立する単一答えはない。□

**手計算例**：一つの受領済みDevice最終観測`D@A`と、Person/Device分離後のPersonの記録欠落を固定する。分離後Personが`U_A`にいる世界と`U_B`にいる世界が両方モデルと整合すれば、Device確認だけからPersonの単位を一意には定められない。これを「DeviceからPersonへ推定してはいけない」の一律禁止とは読まない。再結合・同時観測などの**追加され受領済みの正当な関係**で一方を排除できれば、命題の前提が失われる。

**限界の区別**：
- `C*_t(E)`自体が2単位を含むなら、どんな完全計算方式でも証拠なしに一意化できない（情報の限界）。
- `C*_t(E)`は1単位なのに`C_alg`が2単位を残すなら、その`M,E,q`に対しては近似・探索・実装の限界を疑える。ただし真値包含の検証、推論経路、計算予算は別問題。
- 「異なる履歴がある」だけでは十分でない。2履歴の現在unitが同一なら、履歴は非識別でも現在unitは識別できる。`q_t(h)`が集合値なら、実単位に関する別々の実現可能性を明示する。

**仮定を外した対照**：公開された正しいPerson同時観測が`U_A`だけを許し、cutoffまでに受領されている世界では`h_B∉H_M(E)`。この場合、単一候補の不可能性は導けない。新しい入力がprivate/未来受領なら対照は成立しない。

## 3. 命題II：追加証拠による安全な縮約は条件付き

**命題II-1（既知の集合包含性、直接証明）**。同じ`M,t,q_t`を固定し、既存の`E`に、正当な追加`JointRequirement`命題`e`を1つ採用できる場合、
`H_M(E∧e)=H_M(E)∩S_M(e) ⊆ H_M(E)`、
`C*_t(E∧e) ⊆ C*_t(E)`
が成立する。さらに`h*∈H_M(E)`かつ`h*∈S_M(e)`、写像`q_t`がその真の現在unit`u*_t`を包含するなら、`u*_t∈C*_t(E∧e)`でありモデル内真値を誤除外しない。

**証明**。集合の共通部分は元集合の部分集合である。固定写像で集合を像・和集合に写す操作は包含関係を保つ。真値を含む履歴が共通部分に残り、その像が真の単位を含むので結論を得る。□

**適用範囲**。これは集合論の既知の性質で、新しいFootprintの発見ではない。また`C_alg`について、単調性や真値包含を証明したものではない。`E∧e`が真に連言でないAlternative群なら共通部分は不適切。現行の保守的`outer/preferred/conflict/unknown`仕様や同祖先保留の緩和を命じるものでもない。

**仮定を一つ外した反例**：
1. **誤った証拠**：`Ω={h_A,h_B}`、真値`h*=h_B`、追加命題が誤って`S(e)={h_A}`と宣言されれば、モデル内計算は`U_B`を消し得る。論理的包含の成立と現実への安全性は別。
2. **モデルを変更**：`M_1`では候補が`{U_A}`でも、追加で未知の遷移を許す`M_2`では`{U_A,U_B}`になり得る。`M`固定の命題を更新前後の単調性へ転用できない。
3. **方式が不完全**：真の像が`{U_A}`になっても、保守的な実装が未解決として`{U_A,U_B}`を返すことはある。逆に誤ったhard除外は`C_alg ⊇ C*`を破る。有限テスト合格をすべての入力への証明にしない。
4. **単位写像が部分的**：既知unitが空でも未対応地域が残るなら、単位数0は確認対象0を意味しない（F20の境界）。

## 4. 命題III：一件ずつ価値が0でも、組合せで縮約が生じる

次は**有限な反例を手計算したもの**であり、実シミュレータ結果・一般の救助改善の実証ではない。`Ω={h₁,h₂,h₃,h₄}`、`U={U1,U2}`、対象時刻`t`の像を
`q_t(h₁)=q_t(h₂)={U1}`、`q_t(h₃)=q_t(h₄)={U2}`
と固定する。真値`h*=h₁`は**例の妥当性チェック用**で、推論入力には与えない。受領済みの別々の正しい命題`e₁,e₂`があり、かつ**同じPerson/時刻/母集合に対して同時に成立するJointRequirement**として宣言できるとする。

| 受領済みの制約 | 整合履歴 `H` | 履歴を絞った後の単位像 `C*` |
|---|---|---|
| なし | `{h₁,h₂,h₃,h₄}` | `{U1,U2}` |
| `e₁`のみ（`S(e₁)={h₁,h₃}`） | `{h₁,h₃}` | `{U1,U2}` |
| `e₂`のみ（`S(e₂)={h₁,h₄}`） | `{h₁,h₄}` | `{U1,U2}` |
| `e₁∧e₂` | `{h₁}` | `{U1}` |

よって`|C*(∅)|−|C*({e₁})|=0`、`|C*(∅)|−|C*({e₂})|=0`なのに、両方では1減少する。これは「単独の観測価値だけで横糸を捨てると、相補性を見落とす」**存在例**であり、一般の横糸すべてに価値があるとは言っていない。

**投影順序の非可換性（既知の反例）**：
`q_t(S(e₁)∩S(e₂))={U1}` だが、
`q_t(S(e₁))∩q_t(S(e₂))={U1,U2}`。
ここで`q_t(X)=⋃_{h∈X}q_t(h)`とした。各命題を最初にunitへ投影すると`h₃`と`h₄`を「同じU2」としか区別できず、2命題を同一履歴で満たすかという情報が失われる。前者が後者に包含されることは一般的な集合性質だが、**一致は保証されない**。region単位や履歴数の縮約をunit数の縮約と同一視しない。

**限界効用の反例**：`V(A)=|C*(∅)|−|C*(A)|`（この固定有限例の単位数差）と置くと、`e₂`の限界価値は`A=∅`で0、`A={e₁}`では1。したがって「情報価値が一般に劣モジュラで貪欲な一件ずつの採用でよい」とは言えない。これは**この`V`の反例**であり、情報理論の相互情報量や現場の費用を評価したものではない。

**論理役割を外した反例**：`e₁,e₂`が「どちらか一方かもしれない」`Alternative`なら、`S(e₁)∪S(e₂)={h₁,h₃,h₄}`で単位は`{U1,U2}`のまま。すべての受領記録を自動的にANDに変えると虚偽の削減になる。`h₁`の真値も、記録の認証・同時成立の根拠なしには保証されない。

**コピー/同出所/独立の区別**：
- 原記録`e`のコピー`e'`が同じ命題なら`S(e)∩S(e')=S(e)`。情報制約は冪等であり、独立な裏付け件数にも加算しない。
- 同じ出所から得た**異なる妥当な**命題`e₁`と`e₂`は、同時成立を確認できれば論理積の対象になり得る。出所が同じだけでAND禁止とはならない。
- source ancestryは出所・コピー・導出関係の監査、`JointRequirement/Alternative/EquivalentSupport/NonRestricting`は論理役割、統計的独立性は誤り・確率分布に関する仮定であり、互いを代用しない。既存F14の契約を変更しない。独立した**検証**と、同じsourceから別命題を論理的に採用することも別。

## 5. 数理の問いからシミュレーション・実データへ

| 数理命題/境界 | 固定した条件で判別するシミュレーション案（**本PRでは実行しない**） | 現実で別途確認する仮定 |
|---|---|---|
| I：情報の非識別性 | 同一公開`M`、同一`E_τ`でPerson/Device分離後の異なる真値世界を二つ構成し、外側が両方を保持するか確認。次に正当なPerson横糸を一つ追加した対照を置く | Person/Device同一性、別物体への追随仮定、観測主体と対象の取り違え率、受領遅延 |
| II：履歴交差・安全な投影 | 固定`M,t,q,τ`で真値を隠して各方式へ同一受領入力を渡し、`C*`を有限列挙の参照値として、`outer⊇C*`、unknown/矛盾と演算量を別々に監査 | 移動モデルの閉包性、時刻誤差、地域→unit写像、未表現の移動、観測の正確さ |
| III：相補性・投影順序 | 4履歴/2unitの`e₁,e₂`を**同じ世界・同じ受領時刻・同じ公開関係**で与え、履歴交差→unit投影と、各証拠unit投影→unit交差を比較。各方式に同一の使える証拠を渡す | 2命題のJoint成立条件、source ancestryの監査可能性、観測出所と論理役割の正しさ、実地のunit意味 |
| I–III共通の未成立条件 | private/future、Device-only、同一原記録のコピー、Alternative、矛盾、未対応unitを負対照にし、空集合を「捜索不要」としない | 入手可能性、原記録同定、誤記録率、公開地図/移動時間の妥当性 |

**情報量と方式差の分離**：方法比較では`M, E_τ, t, τ, U`と公開モデル、実際に利用可能な証拠を方法間で同一にし、方式の操作だけを変える。受領遅延や証拠追加を調べる実験は**別軸**にする。真値は評価時にだけ参照し、`FalseExclusion`、外側/優先候補、known unit数/未対応、確認単位の差、最初に役立つ照会時刻、計算量を別々に測る。確認単位数を救助時間・費用・救命率へ未校正のまま換算しない。

**次の実験へ渡す問い（1件）**：この4履歴/2unit・Joint二命題の例を既存の受領・source契約で表現できる場合、**「履歴を保持して連言してからunitへ投影する方式」は「各命題を先にunitへ投影してから交差する方式」より、同じ公開入力で真値を誤除外せずに確認単位を減らせるか**。単なる異名の同一処理を比較しない。先に現mainのF14/F20/M1-Eおよび#132を点検し、既存の論理役割/投影経路でこの操作差が実在するかを独立範囲審査で確定する。実在しなければその違い自体を**未実装の研究仮説**と明記し、新しい実験を発明しない。優位・同等・悪化いずれも受け入れる。

## 6. 先行成果との関係、まだ言えないこと

- [F14 constraint composition](m1f14-constraint-composition-contract.md)：source relationshipと`JointRequirement/Alternative/EquivalentSupport`を独立に宣言する既存の契約。**今回の論理積・冪等性は既知性質**であり、F14がすでに実装した同義のフィルタを新規成果に数えない。本ノートの差分は**全履歴の識別限界と確認単位への投影順序**を定式化し、方式差を判別する問いを立てたこと。
- [F20 public mapping](m1f20-public-search-mapping.md)：candidate/region/unit、many-to-one/one-to-many、未対応unitと動作対象の分離が先行している。`C*`を無条件の現場捜索面積として用いない。
- [F21 finite coverage](m1f21-public-transition-coverage-results.md)：有限・宣言済み閉モデルでの検査を、一般証明や現実の移動の網羅へ拡張しない。**本ノートの命題は固定モデル下の論理であり、F21実装の完全性証明ではない**。
- [M1-D](m1d-causal-tracing.md) / [M1-E method correction](m1e-method-composition-fix.md) / [M1-F ablation](m1f-observation-ablation.md)：既知の公開関係追跡、候補再構成と検証、観測familyの切替を混同しない。既存の同種比較値は再実行・再掲で新発見化しない。
- [#132](https://github.com/uobnnisiuk/footprint-sim/issues/132)の**構造上同値**を横糸全体が無価値だという陰性結果にしない。逆に今回の合成例をもって現行4方式が相補性を実装済みとも呼ばない。
- [#65 / F22](https://github.com/uobnnisiuk/footprint-sim/issues/65)の実歩行記録・探索的比較は既存成果のまま。実測系列のモデル適合と確認場所への情報価値は別。元データの再取得、新しい実験、個人位置の処理は今回なし。
